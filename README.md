Day-wise JavaScript exercises from semester 2. Each day has a small HTML page that loads a script, so you can run it in the browser and watch the output in the console.

## Contents

| Folder | Topics |
| --- | --- |
| `Day_1/` | Conditionals: `if`/`else`, nested conditions, `switch` |
| `Day_2/` | Loops, `break`/`continue`, string methods (`slice`, `split`) |
| `Day_3/` | Arrays: creating, indexing, modifying, filling and summing |
| `Practice/` | Mixed practice problems |

## Run it

Open any `index.html` (or `Practice/P1.html`) in a browser, then open DevTools → **Console**.
